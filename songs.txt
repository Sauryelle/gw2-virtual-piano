Sarya's Music Thingy — Song Library file
=========================================
Host this file as "songs.txt" in the same folder as index.html and the
Library tab (Tome Viewer → Library) will load it automatically.
You can also import this same content by hand: Library → Import → Load .txt.

THE FORMAT
----------
* Every song begins with a header line that starts with three hashes:

      ### Song Name - Artist

  The part after the LAST " - " becomes the artist. The artist is
  optional — "### Song Name" alone works too.

* Everything between one header and the next is that song's tab,
  exactly as you'd paste it in game. Blank lines are fine.

* Lines above the first ### header (like this whole explanation) are
  ignored, so you can keep notes up here.

FILLING IT FROM YOUR GOOGLE DOC
-------------------------------
1. Open the doc → File → Download → Plain text (.txt)
2. For each song, replace its title line with a ### header
   (e.g. "Evenstar" under "Lord of The Rings" becomes
   "### Evenstar - Lord of The Rings")
3. Delete decorative lines you don't want (dividers, counters, etc.)
4. Save as songs.txt next to index.html — done.
